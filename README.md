# ระบบจัดการความสะอาดห้องน้ำ โรงพยาบาลบ่อพลอย (Restroom Cleaning Log System)

ระบบ Web Application สำหรับบันทึก ตรวจสอบ และวิเคราะห์ข้อมูลความสะอาดของห้องน้ำภายในโรงพยาบาลบ่อพลอย โดยพัฒนาขึ้นบน **Google Apps Script (GAS)** และทำงานร่วมกับ **Google Sheets** เพื่อเป็นฐานข้อมูล[cite: 1] ระบบออกแบบมาให้ใช้งานง่าย รองรับการแสดงผลทุกหน้าจอ และมีฟังก์ชันการพิมพ์รายงานสรุปผลรายเดือนออกมาเป็นแบบฟอร์ม A4 แนวนอนได้ทันที[cite: 2]

## ฟีเจอร์หลัก (Features)

*   **ระบบเข้าสู่ระบบ (Authentication):**
    *   แบ่งสิทธิ์การใช้งานเป็น **ผู้ดูแลระบบ/ผู้ตรวจสอบ (Admin)** และ **เจ้าหน้าที่/ไม่ใช้บัญชี**[cite: 1, 2]
    *   เพิ่มความปลอดภัยของรหัสผ่านผู้ดูแลระบบด้วยการ Hash ผ่านอัลกอริทึม SHA-256 พร้อมการทำ Salting (ค่า Salt: `Hosp!tal_Salt_99`)[cite: 1]
*   **การบันทึกความสะอาด:**
    *   เจ้าหน้าที่สามารถเลือกชื่อและสถานที่รับผิดชอบได้อย่างสะดวกรวดเร็ว[cite: 2]
    *   มีรายการตรวจเช็ค 9 หัวข้อหลัก เช่น พื้น, ผนัง/เพดาน, โถส้วม, อ่างล้างมือ, ถังขยะ, กระจก, สบู่, ทิชชู่ ฯลฯ[cite: 2]
*   **ระบบตรวจสอบ (Review System):**
    *   รายการบันทึกจะอยู่ในสถานะ "รอตรวจสอบ"[cite: 1, 2]
    *   ผู้ดูแลระบบสามารถเข้ามาตรวจสอบ บันทึกผลความสะอาด (สะอาด/พบปัญหา) และ "ยืนยัน" รายการได้[cite: 1, 2]
*   **แดชบอร์ดวิเคราะห์ผล (Analytics Dashboard):**
    *   แสดงผลรวมรายการบันทึก รายการรอตรวจสอบ และอัตราส่วนความสะอาด[cite: 2]
    *   แสดง **กราฟแท่ง (Bar Chart)** วิเคราะห์จุดที่มักมีปัญหาความสะอาด[cite: 2]
    *   แสดง **กราฟโดนัท (Doughnut Chart)** วิเคราะห์ประสิทธิภาพของผู้ปฏิบัติงานแต่ละราย[cite: 2]
*   **สรุปรายเดือนและพิมพ์รายงาน (Monthly Summary & Print):**
    *   ระบบประมวลผลข้อมูลรายเดือนแยกตามผู้ปฏิบัติงาน[cite: 2]
    *   สามารถกดพิมพ์รายงาน (Print / PDF) เป็นตารางแบบฟอร์ม A4 แนวนอน (Landscape) เพื่อใช้แนบและลงนามจริงได้ทันที[cite: 2]

## เทคโนโลยีที่ใช้ (Tech Stack)

*   **Backend & Database:** Google Apps Script (GAS)[cite: 1] และ Google Sheets[cite: 1]
*   **Frontend UI:** HTML5, CSS3, JavaScript (ES6)[cite: 2]
*   **CSS Framework:** Tailwind CSS (ผ่าน CDN)[cite: 2]
*   **Libraries:**
    *   [SweetAlert2](https://sweetalert2.github.io/) สำหรับหน้าต่างแจ้งเตือนและ Pop-up[cite: 2]
    *   [Chart.js](https://www.chartjs.org/) สำหรับวาดกราฟแสดงผลการวิเคราะห์[cite: 2]
*   **Typography:** ฟอนต์ `IBM Plex Sans Thai` และ `IBM Plex Mono`[cite: 2]

## โครงสร้างฐานข้อมูล (Google Sheets Setup)

ระบบต้องการ Google Sheets ในการทำงาน โดยแบ่งเป็น 2 ชีตดังนี้:

### 1. `Sheet1` (บันทึกข้อมูลหลัก)[cite: 1]
ให้สร้างชีตชื่อ `Sheet1` สำหรับเก็บข้อมูล (ไม่ต้องตั้งชื่อคอลัมน์เองทั้งหมด แต่โปรแกรมจะทำงานในคอลัมน์ A - W โดยอัตโนมัติ):
*   `A` : Timestamp
*   `B` : Location
*   `C` : Worker
*   `D` : Inspector
*   `E - V` : การกระทำ (Action) และสถานะ (State) ของการตรวจเช็คแต่ละจุด
*   `W` : Status (รอตรวจสอบ / ยืนยันแล้ว)

### 2. `Sheet2` (ตั้งค่าข้อมูล Dropdown)[cite: 1]
ให้สร้างชีตชื่อ `Sheet2` เพื่อใช้เป็นฐานข้อมูลรายชื่อและสถานที่:
*   `A` : รายชื่อผู้ปฏิบัติงาน (เช่น สมชาย ใจดี)[cite: 1]
*   `B` : สถานที่รับผิดชอบ (รองรับหลายสถานที่ในเซลล์เดียว โดยใช้เครื่องหมาย `""` ครอบแต่ละชื่อ เช่น `"สถานที่ 1" "สถานที่ 2"`)[cite: 1]

## การติดตั้งและใช้งาน (Deployment)

1.  สร้างโปรเจกต์ใหม่ใน Google Apps Script
2.  คัดลอกโค้ดทั้งหมดในไฟล์ `Code.gs` วางลงในไฟล์ระดับ Server ของ GAS
3.  สร้างไฟล์ HTML ใหม่ใน GAS ตั้งชื่อว่า `Index.html` และคัดลอกโค้ดส่วน Frontend ไปวาง
4.  ผูก Script กับ Google Sheets ที่เตรียมไว้
5.  ตั้งค่า `ADMIN_EMAIL_HASH` และ `ADMIN_PASS_HASH` ในไฟล์ `Code.gs` ให้ตรงกับรหัสผ่านที่ต้องการ (เข้ารหัส SHA-256 + Salt ก่อนนำมาใส่)[cite: 1]
6.  กด **การทำให้ใช้งานได้ (Deploy)** -> **การสร้างรายการใช้งานใหม่ (New Deployment)**
7.  เลือกประเภทเป็น **เว็บแอป (Web App)** ตั้งค่าให้แอปพลิเคชันทำงานในฐานะคุณ และให้สิทธิ์เข้าถึงแก่ "ทุกคน" (Anyone)
8.  นำ URL ที่ได้ไปใช้งาน
